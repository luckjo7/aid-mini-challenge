# AID 이미지 분류 대회

캠퍼스 사진을 제6공학관(0)과 IT관(1)으로 분류하고 IT관일 확률을 예측한 실험 기록이다. 평가 지표는 Log Loss이며 낮을수록 좋다.

[개선 과정](개선과정.md) · [실험 목록](실험결과/README.md) · [제출 기록](제출기록.md)

## 최종 결과

| 구분 | 구성 | Public Log Loss |
|---|---|---:|
| 최종 제출 | 011 · 분할 seed 17 · 조건부 T0.3 TTA | **0.0066** |
| 실험 중 최고 Public | 005 · 기존 가중치 · 조건부 T0.3 TTA · #80 | **0.0044** |

최종 제출은 사용자가 선택한 011 seed 17이다. 최고 Public 기록과 최종 제출 모델을 구분한다. 점수는 대회 당시 사용자 확인값이며 Private 성적은 최종 제출 기준 0.06이다. 과적합과 과확신이 의심되는 모델이다.

최종 모델은 EfficientNet-B0 네 개(학습 seed 17·18·19·20)의 앙상블이다. 192×192 중앙 크롭과 ImageNet 정규화를 사용하고, 모델마다 원본·좌우 반전 확률을 평균한다. 네 모델 분류가 일치하면 확률 평균에 T=0.3, 불일치하면 가운데 두 확률의 평균에 T=0.7을 적용한다. 전체 파라미터는 16,035,316개다.

## 실행 환경과 재현

대회 당시 기록된 환경은 Python 3.11.18, PyTorch 2.14.1+cu126, Torchvision 0.29.1+cu126, CUDA 빌드 12.6이다. GPU는 NVIDIA GeForce RTX 3080, PyTorch 보고 VRAM 약 20GiB였다. 이 기록을 모든 과거 실행의 환경으로 소급하지 않는다.

추론에는 torch, torchvision, Pillow가 필요하다. 학습·분석에는 numpy, scikit-learn, matplotlib, Jupyter 커널이 추가로 필요하다.

가중치를 이용한 추론과 모델·추론 모듈 복원 방법은 [최종 제출 안내](실험결과/011_192크롭_패딩제거/seed_17/최종제출/README.md)에 있다. 추론만 할 때는 노트북 전체를 실행하지 않고 모델·추론 코드 셀만 복원한다.

노트북은 **당시 코드와 설명을 보존한 보관본**이다. 파일 재배치에 맞춰 코드 경로를 일괄 변경하지 않았다. 과거 실험을 다시 실행하려면 별도 작업 폴더에 다음 구성을 준비한다.

1. 학습데이터 아래의 train/, test/, sample_submission.csv를 작업 폴더 바로 아래에 둔다.
2. 노트북 파일명을 유지하고 작업 폴더를 커널의 현재 디렉터리로 사용한다.
3. 결과·원본 가중치를 재사용하는 실험은 해당 실험결과/ 경로를 준비한다. Places365 사용 실험은 사전학습가중치/의 파일을 작업 폴더에 복사한다.
4. model*.py·predict*.py는 노트북 코드 셀에서 복원한다. 010과 005의 추가 평균 후보는 별도 코드/도 함께 복사한다.

제거한 실행 상태 JSON·이미지별 예측·검증 목록까지 자동 복원되지는 않는다. 특히 000의 완료 실행 재사용과 이를 읽는 010은 당시 설정·검증 목록·확률·해시 기록을 복원하거나 로딩 부분을 수정해야 한다. 가중치와 노트북 보존이 모든 과거 실행의 즉시 재실행을 보장하지는 않는다. [보관 파일 대응표](실험결과/보관파일.md)와 각 실험의 실험설정.md에서 남긴 기록을 확인한다.

## 정리 기준

- 실험별 결과 설명과 분석 문서를 유지했다.
- 내용이 다른 노트북과 SHA-256이 다른 가중치를 모두 남겼다. 같은 내용의 패키지·검수 복사본은 하나로 합쳤다.
- 비교·요약·epoch CSV와 학습곡선을 보존했다. 제출 예시 CSV는 데이터 입력으로 보존했다.
- 개별 예측·제출·자가 검증 CSV, ZIP, 캐시, 검증 임시 코드를 제거했다.
- 보존할 JSON 설정·지표·Public 확인·가중치 출처는 각 실험의 실험설정.md로 옮겼다. TXT 실행 안내는 Markdown 안내에 통합했다.
- 노트북이 생성하는 Python 모듈은 중복 보관하지 않는다. 010과 추가 평균 후보의 독립 추론 모듈만 예외로 보존했다.
- 개별 실험 문서의 산출물 설명과 제출 기록의 파일명은 대회 당시 기록이다. 정리 후 실제 보관 위치는 보관파일.md를 따른다.

## 대회 규칙과 제출

아래는 사용자가 제공한 대회 안내를 정리한 기록이다.

| 항목 | 당시 규칙 |
|---|---|
| 학습 데이터 | 제공된 학습 이미지만 사용. 데이터 증강 허용 |
| 외부 이미지 | 직접 촬영·웹 수집·외부 데이터셋으로 추가 학습 금지 |
| 테스트 이미지 | 학습·pseudo-labeling·self-training에 사용 금지 |
| 사전학습 | 공개된 ImageNet·Places365 가중치 사용 허용 |
| 파라미터 | 최종 추론 모델 합계 20,000,000 이하 |
| 추론 | Colab CPU에서 테스트 500장 600초 이내, 추론 중 다운로드 금지 |
| 예측 파일 | id,prob 헤더, 테스트 500장 전체, 확률 0~1, 최대 10MB |
| 채점 | 확률을 0.000001~0.999999로 제한한 Log Loss |
| 최종 패키지 | 선택한 예측을 재현하는 학습·추론 코드와 전체 가중치, ZIP 200MB 이하 |
| 최종 순위 | Private 점수. 동점이면 파라미터 수가 적은 모델 우선 |

CSV 접수 안내는 2026-11-07 15:00~2026-11-08 21:00 KST였다. ZIP 마감은 당시 본문 23:00과 제출 화면 23:59가 달라 정확한 마감을 확정하지 않았다. 실제 Colab CPU 시간과 사이트 최종 CSV 선택 상태는 별도 확인되지 않았다.

## 결과 해석의 한계

검증은 학습 이미지에서 나눈 표본이고 Public은 별도의 비공개 표본이다. Public 최고점 한 번을 반복 실행의 안정성이나 Private 성능으로 해석하지 않는다. 분할 seed와 모델 초기화 seed를 함께 바꾼 실험은 둘의 효과를 분리하지 못한다. 장면·촬영 연속성 기반 그룹 분할은 검증하지 않았고, 012의 실제 데이터 전체 16회 학습도 수행되지 않았다.
