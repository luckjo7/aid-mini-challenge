# 실험 006 — 분할 변경과 두 temperature 규칙

사용자는 이번 실험을 새 학습으로 수행하며, SEED=1로 시작한다.
모델·증강·입력·손실 기준은 실험 005의 설정을 사용한다.

현재 저장된 baseline.ipynb·model.py·predict.py를 [코드](코드/)에 보관했다.
이 보관본은 복사 시점의 저장 파일 스냅샷이다.

## 시드와 저장 경로

- SEED는 데이터 분할 시드다.
- 모델 시드는 SEED부터 연속된 네 개로 자동 설정한다.
- SEED=1이면 모델 1·2·3·4, SEED=42이면 모델 42·43·44·45다.
- 각 모델에 기본형·강규칙형·가림·원근 변형을 차례대로 적용한다.
- 결과는 이 실험 폴더 아래 seed_1, seed_42처럼 분할 시드별 하위 폴더에 저장한다.
- 새 분할에서는 네 모델을 ImageNet 사전학습 가중치에서 새로 학습한다.
- runs.csv와 ensemble.pt에 분할 시드와 개별 모델 시드를 함께 기록한다.

## 모든 테스트에서 함께 생성하는 두 규칙

네 모델의 의견이 일치하면 확률 평균, 불일치하면 정렬한 가운데 두 확률의 평균을 사용한다.

| 이름 | 전원 일치 | 불일치 |
|---|---|---|
| T0.3 | T=0.3 | T=0.7 |
| T0.5 | T=0.5 | T=0.5 |

T0.3은 기존 조건부 규칙의 파일명이다. 모든 사진에 T=0.3을 적용한다는 의미가 아니다.
별도의 CSV 후처리 셀을 제거하고, 테스트 추론 셀에서 같은 개별 모델 확률로 두 규칙을 동시에 계산한다.
보정된 CSV에 temperature를 다시 적용하는 절차는 사용하지 않는다.

SEED=1의 주요 제출 파일은 다음과 같다.

- submission_1_T0.3.csv
- submission_1_T0.5.csv

SEED=42이면 submission_42_T0.3.csv와 submission_42_T0.5.csv가 된다.
개별 모델 CSV도 submission_1_seed1.csv처럼 분할 시드와 모델 시드를 포함한다.

## 검증과 제출

검증 전체·의견 일치 유형별로 두 규칙의 ACC·Log Loss를 함께 기록한다.
제출 ZIP의 predict.py는 --temperature-rule T0.3 또는 --temperature-rule T0.5로 해당 CSV를 재현한다.
자가 검증 셀은 두 규칙을 각각 CPU에서 실행하고 생성된 제출 CSV와 대조한다.

사용자는 유망한 모델의 설정을 바꿔 여러 차례 직접 CSV를 제출할 계획이다.
제출 후보는 분할 시드·모델 시드·증강·temperature 규칙과 함께 관리한다.
Public 점수 변화와 새로운 분할의 검증 성적을 함께 확인한다.

## 이전 결과

실험 005의 분할 시드는 42였으며 모델 시드는 42·43·44·45였다.
사용자 최종 확인 기준 기존 조건부 T0.3 규칙의 Public Log Loss는 0.0045, 전체 T0.5 규칙은 0.0047이다.
실험 005 폴더의 submission_42_T0.3.csv와 submission_42_T0.5.csv는 각각 500개 ID와 해당 규칙의 계산 결과를 대조해 확인했다.
이전 코드의 수정 직전 보관본은 archive/005_LogLoss4모델_비율보존에 있다. 보관본의 SEED는 사용자가 이미 1로 수정한 상태이므로 과거 실행 당시 코드와 완전히 같다는 의미는 아니다.

## 완료 결과와 Public 제출 — 2026-11-08 추가 확인

네 모델 학습과 두 temperature CSV 생성이 완료됐다. 최종 개별 결과는 runs.csv를 참조한다.

| 구성 | 검증 ACC | 검증 Log Loss | Public Log Loss |
|---|---:|---:|---:|
| 단순 확률 평균 T=1 | 99.54% (434/436) | 0.01679908 | 미기록 |
| 중앙 두 확률 평균 T=1 | 99.31% (433/436) | 0.01274296 | 미기록 |
| T0.3 규칙 | 99.31% (433/436) | 0.01283845 | **0.0289** |
| T0.5 규칙 | 99.31% (433/436) | 0.01549431 | 미기록 |

Public 0.0289는 사용자가 seed_1/submission_1_T0.3.csv를 제출한 결과다. 005 T0.3의 Public 0.0045보다 높다.

확인한 제출 파일은 500개 ID가 sample_submission과 일치하고 중복·누락·비정상 확률이 없다. 개별 모델 CSV에서 현재 결합 규칙으로 재계산한 값과 최대 차이가 약 0.00000067로, 소수 여섯 자리 CSV 저장 정밀도 수준이다. 이는 저장 확률의 결합·파일 형식 확인이며 가중치로 다시 수행한 전체 추론 검증과 구분한다.

005와 006의 T0.3 CSV를 비교하면 테스트 이미지 500장 중 6장의 최종 분류가 반대로 바뀌었다. 네 모델의 의견 불일치 이미지도 16장에서 22장으로 늘었다. Public 정답과 포함 이미지가 비공개이므로 실제 점수 상승을 일으킨 이미지를 특정할 수는 없다. Public 250장에서 한 이미지에 정답 확률 0.001을 주면 그 한 장의 손실 기여만 약 0.02763이다.

006에서는 중앙값 결합으로 단순 평균보다 검증 오답이 한 장 늘었다. 반면 Log Loss는 감소했으므로 두 지표를 구분해 판단한다. seed 2 strong의 좋은 검증 성적만으로 전체 앙상블의 Public 성능을 예측할 수 없고, 005와 분할·초기화 시드가 함께 달라진 점도 고려한다.

## 일반화 판단

005 대비 Public 점수 상승은 분할·초기화에 따른 성능 변동이 크다는 관찰이다. 이 결과만으로 과적합을 확정하지 않는다. 최고점 한 번보다 반복 실행에서의 안정성을 확인해야 하며, 새 학습에서 점수가 높아졌다고 기존 005 모델의 Private 성능이 나쁘다고 단정하지 않는다.
