# 실험 008 — MobileNetV3 Large + EfficientNet-B0 이종 앙상블

분할 seed 1·42의 CSV 생성과 Public 결과를 확인했다. TTA Public은 seed 1이 #59 0.0133, seed 42가 #58 0.0232다. 아래 산출물 상세 검수는 seed 42 기준이다.

## 목적과 구성

007의 첫 번째 strong 모델을 MobileNetV3 Large로 교체해 오답 겹침과 앙상블 Log Loss의 변화를 확인한다. 교체 위치는 두 분할에서 동일하게 고정한다.

| 모델 seed | 구조 | 증강 | 준비 방식 |
|---|---|---|---|
| SEED | MobileNetV3 Large | strong | ImageNet 사전학습 가중치에서 새로 학습 |
| SEED+1 | EfficientNet-B0 | strong | 같은 분할의 007 가중치 재사용 |
| SEED+2 | EfficientNet-B0 | strong+가림 | 같은 분할의 007 가중치 재사용 |
| SEED+3 | EfficientNet-B0 | strong+원근 | 같은 분할의 007 가중치 재사용 |

이진 분류 출력층 기준 총 파라미터는 16,229,800개다. 분할·전처리·증강·optimizer·학습률·종료·선택 조건은 007과 같다. MobileNet의 사전학습 가중치는 Torchvision ImageNet V1을 사용한다.

## 실행

- 실제 실행 파일은 루트의 `baseline_test2.ipynb`다. 007과 동시에 사용할 때는 별도 커널을 선택한다.
- 시작 설정은 `SEED = 42`다. 같은 노트북에서 `SEED = 1`로 바꾸고 처음부터 실행해 반복한다.
- 모델·추론 코드는 `model_test2.py`, `predict_test2.py`로 생성한다.
- MobileNet을 먼저 학습할 수 있다. 이후 ‘007 B0 재사용’ 셀은 해당 세 모델의 완료 기록·증강·학습 설정·가중치를 확인한다. 007 완료 전이면 완료 후 이 셀부터 이어 실행한다.
- 결과는 `seed_{SEED}/`에 저장한다. `runs.csv`에 새 학습과 재사용 여부 및 원본 가중치 경로를 기록하고, 재사용한 epoch CSV와 그래프도 복사한다.
- 노트북을 저장한 뒤 학습을 시작한다. 실행 시점의 저장본과 모델 코드를 `seed_{SEED}/코드/`에 보관한다.

## 제출과 검증

최종 제출 CSV는 다음 두 개다.

```text
submission_{SEED}_T0.3.csv
submission_{SEED}_T0.3_TTA.csv
```

조건부 T0.3은 전원 일치 시 네 확률 평균에 T=0.3, 불일치 시 가운데 두 확률 평균에 T=0.7을 적용한다. TTA는 각 모델의 원본·좌우 반전 확률을 평균한 뒤 같은 규칙을 적용한다.

두 방식의 검증 지표·의견 일치 유형·이미지별 확률을 저장한다. 제출 CSV의 500개 ID와 확률 형식을 검사한다. 최종 ZIP에는 008 코드와 네 모델 가중치, 재사용한 B0의 007 학습 코드 및 출처 기록을 포함한다.

008 앙상블 추론에서는 CPU 재현 차이를 줄이기 위해 cuDNN TF32를 끈다. 학습 계산 설정은 유지한다. 따라서 같은 B0 가중치도 기존 007 GPU 추론과 미세한 수치 차이가 발생할 수 있다.

```shell
python predict_test2.py --input test --output pred.csv
python predict_test2.py --input test --output pred_tta.csv --tta
```

패키지 자가 검증에서 두 방식의 CPU 소요 시간과 CSV 재현 차이를 확인한다. 실제 Colab CPU 600초 제한은 최종 후보에서 확인한다. `summary.csv`의 모델 간 표준편차는 서로 다른 구성 모델의 기술 통계이며 반복 학습의 오차범위를 나타내지 않는다.

## seed 42 완료 검토 — 2026-11-08

MobileNet은 35 epoch 학습했고, 19 epoch의 최저 검증 손실 가중치를 선택했다. 학습 시간은 약 269초다. 나머지 세 B0는 007 seed 43·44·45 가중치와 모든 텐서가 동일함을 확인했다.

| 비교 | 007 검증 Log Loss | 008 검증 Log Loss | 오답 수 변화 |
|---|---:|---:|---|
| 교체한 첫 모델 | 0.01476 | 0.02573 | 3 → 2 |
| 앙상블 T0.3 | 0.00508 | 0.00402 | 2 → 1 |
| 앙상블 T0.3 TTA | 0.00574 | 0.00420 | 3 → 1 |

007·008의 검증 사진 436개 ID와 정답이 모두 일치했다. 원본 지표는 [ensemble_metrics.csv](seed_42/ensemble_metrics.csv), 이미지별 확률은 `validation_predictions.csv` (과거 산출물; 현재 파일 없음)에 있다. 007 TTA 비교값은 007 최종 검토에서 가중치로 재계산한 검증 결과다.

MobileNet 단독 손실은 기존 B0보다 높지만 앙상블에서는 기존 오답 f96ae15b-9079-4a03-8533-14f26a46894b를 고쳤고 새로운 오답은 없었다. 해당 사진의 정답은 제6공학관이다. IT관 확률은 007 앙상블의 0.56474에서 008의 0.42766으로 낮아졌다. MobileNet이 새로 틀린 eb7c5992-38e2-4bbc-8a34-d371b4dee0ce는 다른 모델이 보완해 앙상블에서 맞혔다.

008과 같은 TF32 비활성화 조건으로 007 가중치를 재추론했을 때 기본 T0.3 손실은 0.00507224, 오답은 2장이었다. 계산 정밀도를 맞춘 비교에서도 008의 약 21% 손실 개선이 유지됐다.

### 산출물 검수

- 두 제출 CSV는 각각 테스트 500개 ID를 정확히 포함하고 중복·누락·비정상 확률이 없었다.
- 최종 ZIP은 61,502,433바이트다. ZIP 내부 오류 검사와 필수 파일의 패키지 폴더 대응을 통과했다.
- ZIP의 model.pt와 ensemble.pt가 일치하고, 내부 모델 구조·seed·네 체크포인트가 모두 대응했다.
- 총 파라미터는 16,229,800개다.
- 패키지 추론 코드를 로컬 CPU에서 500장씩 다시 실행했다. 기본 T0.3은 약 15.74초·CSV 최대 차이 0.000001, TTA는 약 27.34초·최대 차이 0.000002였다.
- 위 시간은 로컬 CPU 측정이다. 실제 Colab CPU 시간은 미확인이다.

### 판단

seed 42에서는 이종 모델 교체가 오답 보완과 앙상블 손실 감소로 이어졌다. 현재 검증 기준으로 기본 T0.3을 우선 제출 후보로 둔다. seed 1과 Public 결과를 함께 확인해 채택 범위를 결정한다.

### Public 결과 추가 확인

사용자 최신 확인값은 007 seed 42 TTA가 #57 0.0109, 008 seed 42 TTA가 #58 0.0232다. 이전 대화에서 008 TTA를 0.0109로 해석한 대응은 정정한다. 제출번호·CSV 경로는 [제출 기록](../../제출기록.md)에 있다.

같은 분할 seed와 TTA 방식에서 검증 Log Loss는 007 약 0.00574 → 008 약 0.00420으로 감소했지만, Public은 0.0109 → 0.0232로 증가했다. 이종 모델의 해당 검증셋 보완 효과가 Public 개선으로 이어지지 않았다. Public 정답과 구성 이미지가 비공개이므로 원인 사진이나 Private 우열은 확정할 수 없다. seed 42 기본 T0.3 Public 점수는 두 실험 모두 미확인이다.

seed 1 TTA는 #59 0.0133으로 확인됐다. 같은 분할의 007 TTA #54 0.0176보다 낮다. 사용자는 008 seed 1의 TTA 미적용 CSV를 별도 제출하지 않을 계획이며 해당 Public은 미평가다. 모델 교체의 Public 효과는 seed 1에서 개선, seed 42에서 악화로 방향이 달랐다.
