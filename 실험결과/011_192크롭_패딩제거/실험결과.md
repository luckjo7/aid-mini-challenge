### seed 변경 재실행 수정 — 2026-11-08

사용자가 상단 SEED를 17로 바꿨지만 RUN_SEEDS와 결과 경로가 42로 고정돼 있어, 기존 seed_42 결과 보호 검사에서 중단됐다. 상단 SEED에서 모델 seed 네 개·증강 대응·결과 폴더·CSV 및 자가 검증 파일명을 도출하도록 수정했다. 추론 코드의 42~45 고정 검사도 연속된 네 seed와 증강 순서 검사로 바꿨다.

현재 상단 설정 17은 유지했다. 새 학습은 분할 seed 17·모델 seed 17/18/19/20이며 결과는 seed_17/에 저장한다. 이후에는 SEED 한 곳을 변경하고 노트북을 저장한 뒤 커널 재시작·전체 실행한다. 위와 아래의 seed 42 성적은 이전 완료 실행의 기록이며 변경하지 않는다.

임시 폴더에서 seed 17의 경로·가중치 연결·세 CSV 및 ZIP 생성·CPU 재현을 테스트했고 모두 차이 0이었다. 기존 seed 42 산출물 보호 검사와 해시 불변도 확인했다. 이 검사는 무작위 초기 가중치·테스트 2장으로 수행했으며 수정 검증 당시에는 새 seed 전체 학습을 실행하지 않았다. 이후 사용자의 실제 완료 결과는 아래 seed 17 기록에 추가했다.

## 구성

| 학습 seed | 크롭·증강 | 밝기·대비 | 채도 |
|---|---|---|---|
| 42 | 정사각형 | ±30% | ±20% |
| 43 | 직사각형 허용 | ±40% | ±30% |
| 44 | 정사각형+가림 | ±30% | ±20% |
| 45 | 정사각형+원근 | ±30% | ±20% |

- 원본 실제 사진에서 위치를 무작위 선택한다. 크롭의 각 변은 정수 96~192픽셀이다.
- 정사각형은 두 변이 같다. 50%는 한 변 기준 96픽셀로, 면적 기준으로는 192×192의 25%다.
- 직사각형은 두 변을 따로 선택하되 기존 종횡비 0.75~1.333 범위를 유지한다. 두 변 모두 192를 넘지 않는다. 최종 192×192 확대 시 비율 변형을 허용한다.
- 좌우 반전 50%, seed별 색상 변형은 005와 같다.
- 가림: 확률 10%, 최종 이미지 면적 2~10%, 정규화 후 0으로 채움.
- 원근: 확률 30%, distortion_scale=0.15. 원근 모서리 채움 RGB (124, 116, 104)는 남으며 크기 맞춤 패딩과 구분한다.
- 최종 학습 입력은 192×192. resize_pad를 사용하지 않는다.
- 검증·추론은 192×192 중앙 크롭과 ImageNet 정규화로 동일하다. 192보다 작은 이미지에 패딩으로 대응하지 않고 오류를 발생시킨다.

## 학습·평가

- EfficientNet-B0 ImageNet V1, 전체 미세조정. 모델당 4,008,829개, 앙상블 16,035,316개 파라미터.
- 분할 seed 42, 층화 검증 15%: 학습 2,470장·검증 436장. 005 검증 이미지 ID 436개와 정확히 일치함을 확인했다.
- Adam, batch size 32, workers 0. 최대 50 epoch.
- 학습률 0.001 → 0.0003 → 0.0001. 단계별 최소 5 epoch 후 연속 5회 검증 손실 미개선 시 전환. 마지막 단계 정체 시 종료.
- 전체 최저 검증 Log Loss 체크포인트. 동률 시 높은 ACC를 선택한다.
- TF32 비활성화. 배치 진행 막대 없이 epoch별 CSV를 즉시 기록하고 완료 모델별 runs.csv를 저장한다.
- 전원 일치 시 네 확률 평균, 불일치 시 가운데 두 확률 평균. 조건부 T0.3은 전원 일치 T=0.3·불일치 T=0.7. 전체 T0.5도 계산한다.
- TTA는 각 모델의 중앙 크롭·좌우 반전 확률 평균 후 같은 결합 규칙을 적용한다.
- 검증 개별 확률·TTA 확률·규칙별 지표·의견 일치별 오답을 보관한다. 테스트 CSV는 CPU 추론으로 생성한다.
