## 사용자 확정 구성

| Fold | 네 증강의 공통 학습 seed | 학습 횟수 |
|---|---:|---:|
| 1 | 42 | 4 |
| 2 | 43 | 4 |
| 3 | 44 | 4 |
| 4 | 45 | 4 |

매 fold에서 정사각형, 직사각형 허용, 정사각형+가림, 정사각형+원근 모델을 하나씩 새로 학습한다. 총 16회다. 모델·optimizer·DataLoader를 매번 새로 생성하며 이전 실험 체크포인트는 재사용하지 않는다. 출발 가중치는 ImageNet 사전학습 EfficientNet-B0 V1이다.

## 011에서 유지한 설정

- 학습 크롭 각 변 96~192픽셀. 정사각형은 두 변이 같고, 직사각형은 두 변을 따로 선택하되 가로/세로 0.75~1.333 범위를 유지한다.
- 크롭을 192×192로 확대하고 직사각형 비율 변형을 허용한다. 크기 맞춤 패딩은 없다. 검증·추론은 192×192 중앙 크롭과 ImageNet 정규화다.
- 좌우 반전 확률 50%. 직사각형 모델의 밝기·대비 ±40%·채도 ±30%, 나머지 ±30%·±20%.
- 가림 확률 10%·면적 2~10%·정규화 후 0 채움. 원근 확률 30%·distortion_scale=0.15·모서리 채움 RGB (124, 116, 104).
- Adam, batch size 32, workers 0, 최대 50 epoch. 학습률 0.001 → 0.0003 → 0.0001.
- 단계별 최소 5 epoch 후 연속 5회 검증 손실 미개선 시 전환하고 마지막 단계 정체 시 종료한다. 전체 최저 검증 손실 체크포인트를 선택한다.
- TF32 비활성화. 배치별 진행 막대 없이 epoch별 CSV를 즉시 저장한다.
- 전원 일치 시 네 확률 평균·불일치 시 가운데 두 확률 평균. 조건부 T0.3은 일치 0.3·불일치 0.7이다. 전체 T0.5와 좌우 반전 TTA도 평가한다.

## Cross-validation과 OOF

StratifiedKFold(n_splits=4, shuffle=True, random_state=42)를 한 번 생성한다. 네 증강 모두 동일한 fold 인덱스를 사용한다. 4회 무작위 holdout과 구분한다.

실제 2,906장에 대한 분할 확인 결과:

| Fold | 학습 | 검증 | 검증 6e / it |
|---|---:|---:|---|
| 1 | 2,179 | 727 | 367 / 360 |
| 2 | 2,179 | 727 | 366 / 361 |
| 3 | 2,180 | 726 | 366 / 360 |
| 4 | 2,180 | 726 | 366 / 360 |

각 사진은 정확히 한 번 검증에 들어간다. 학습/검증 인덱스 비중복과 전체 검증 1회 피복을 검사한다. 모델별 최저 손실 가중치를 불러온 뒤 해당 fold 검증셋에만 원본·좌우 반전 추론을 수행한다. 전체 OOF 배열에서 사진·증강별 예측 횟수가 정확히 1인지 검사하며 누락·비유한 확률이 있으면 중단한다.

각 OOF 행의 네 확률은 같은 사진을 학습하지 않은 같은 fold 모델에서 나온다. 다른 fold 모델을 검증 앙상블에 추가하지 않는다. 전체 OOF Log Loss는 전체 2,906장 예측을 모아 계산하며 fold별 손실의 단순 평균과 구분한다.

## 최종 제출

전체 16모델은 64,141,264개 파라미터로 제한을 넘는다. 제출에는 한 fold의 네 증강 모델만 사용하며 16,035,316개다.

제출 fold 선택 셀의 SUBMISSION_FOLD 기본값은 1이다. 검증 점수로 자동 선택하지 않는다. 다른 fold를 내보내려면 1~4로 바꾸고 해당 셀부터 아래만 실행한다. 16회 학습은 다시 실행하지 않는다.

선택 fold N·seed S에 대해 다음 CSV와 ZIP을 생성한다.

| CSV | 대응 ZIP |
|---|---|
| submission_foldN_seedS_T0.3.csv | submission_package_T0.3.zip |
| submission_foldN_seedS_T0.5.csv | submission_package_T0.5.zip |
| submission_foldN_seedS_T0.3_TTA.csv | submission_package_T0.3_TTA.zip |

ZIP에는 선택한 네 가중치, model.py, predict.py, 학습 당시 baseline_test6.ipynb, training_record.json, fold_assignments.csv, README.txt를 포함한다. 기본 실행 명령은 세 ZIP 모두 동일하며 각 ZIP의 기본 규칙이 대응 CSV를 재현한다.

```text
python predict.py --input <test 폴더> --output pred.csv
```

CSV는 CPU 4스레드에서 생성한다. ZIP의 200MB 제한·무결성을 검사하고 실제 ZIP을 풀어 기본 명령으로 500장 CSV 재현을 확인한다. 실행별 600초 이하·최대 확률 차이 0.00001 이하를 검사하며 package_check.json에 CSV·ZIP 해시와 시간을 기록한다. 로컬 CPU와 실제 Colab CPU 시간은 구분한다.

## 작성 시 검증

- 노트북 형식·전 코드 셀 문법·내장 코드와 루트 모듈의 일치 확인.
- 실제 사진 2,906장에 대한 층화 분할 수량·클래스 수·학습/검증 비중복·검증 전체 1회 피복 확인.
- 임시 합성 사진 16장과 테스트 2장으로 실제 B0 16개를 무작위 초기 가중치에서 각 1 epoch씩 CPU 학습했다. 최종 학습이나 모델 성능 평가가 아니다.
- 각 fold의 네 모델 초기 가중치 해시와 seed가 동일하고, fold 간 seed가 42/43/44/45로 다른 것을 확인했다.
- 학습/검증 인덱스 비중복, 16개 체크포인트 생성, OOF 사진·증강별 정확히 1회 예측 확인.

- 기본값과 다른 fold 4·seed 45의 네 모델을 선택해 세 CSV·세 ZIP을 생성했다. ZIP 기본 명령으로 CPU 재현 시 세 방식 모두 최대 차이 0.
- 원래 011 노트북·모델·추론 코드 및 기존 루트 model.py·predict.py가 변경되지 않았음을 해시로 확인했다.

전체 16회 실제 데이터 학습, 최종 테스트 500장 CPU 시간, 실제 Colab CPU 시간, Public 성적은 아직 확인하지 않았다.

## 해석 범위

fold마다 학습 데이터와 seed가 함께 달라 fold 간 차이를 seed 하나의 효과로 분리하지 않는다. 같은 fold 안에서도 증강에 따라 난수 소비가 달라 모든 사진 변형까지 동일하지는 않다. 검증셋으로 체크포인트를 선택하므로 OOF를 완전히 독립적인 테스트 성적으로 해석하지 않는다. 전체 OOF 성능과 선택한 한 fold의 최종 테스트 성능은 구분한다.
