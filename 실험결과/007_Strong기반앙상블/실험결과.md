# 실험 007 — Strong 기반 4모델 앙상블

분할 seed 1·42의 네 모델 학습과 앙상블 CSV 생성 완료. 작업용 노트북은 루트의 baseline_test.ipynb다.
분할 seed 1과 모델 시드 1·2·3·4로 실행할 수 있도록 설정했다.

## 실행 위치와 코드 보관

실제 실행은 기존 프로젝트 루트의 baseline_test.ipynb에서 수행한다. 작업 디렉터리도 프로젝트 루트로 둔다.
현재 노트북의 복사본은 [코드/baseline_test.ipynb](코드/baseline_test.ipynb)에 보관했다.
이 복사본도 007 설정을 반영한 현재 저장본으로 갱신했다.
학습 시작 셀에서 저장된 baseline_test.ipynb와 model.py를 seed_{SEED}/코드/에 자동 복사한다.
실행 전에 루트 노트북을 저장한다. 실제 실행 시점의 복사본을 제출 ZIP에도 포함한다.
실험 폴더에는 결과와 코드 스냅샷을 함께 보관한다.

## 목적

현재 실험 006의 기본·강규칙·기본+가림·기본+원근 구성을,
강규칙·강규칙·강규칙+가림·강규칙+원근 구성과 비교한다.
기존 기록에서 strong의 개선이 관찰됐지만 입력 방식과 학습 기준도 달라졌으므로, 실험 006과 동일한 조건에서 증강 기준만 바꿔 확인한다.

## 적용 설정

분할 시드는 실험 006과 같은 SEED=1로 둔다. 모델 시드는 1·2·3·4다.
앞으로 SEED를 변경하면 모델 시드 4개와 제출 이름이 함께 바뀌는 규칙을 유지한다.

| 모델 시드 | 증강 |
|---|---|
| SEED | strong |
| SEED+1 | strong |
| SEED+2 | strong + Random Erasing |
| SEED+3 | strong + Random Perspective |

모두 크롭 면적 50–100%, 밝기·대비 ±40%, 채도 ±30%, 좌우 반전 확률 0.5를 사용한다.
가림은 확률 10%, 면적 2–10%다.
원근은 확률 30%, distortion_scale=0.15다.
두 strong 모델은 서로 다른 시드를 사용한다.
SEED+1 모델은 실험 006에서도 strong이므로 같은 증강 조건의 비교 기준이 된다.

입력은 비율 보존 256×256 패딩, 검증 분할·학습률·최대 epoch·optimizer·batch size·workers는 실험 006과 같게 둔다.
네 모델 모두 최저 검증 Log Loss를 저장한다. 학습률별 최소 5 epoch 이후 연속 5회 단계 내 손실 미개선 시 전환하고, 마지막 단계에서는 종료한다.
최대 50 epoch 상한을 적용한다.

## 구현한 내용

1. baseline_test.ipynb에서 모델별 증강 설정을 strong 기반으로 변경한다.
2. 결과 경로를 이 폴더의 seed_{SEED} 하위로 지정한다.
3. 제출 ZIP에 실제 학습 코드인 baseline_test.ipynb를 포함하도록 패키지 생성 셀을 수정한다.
4. 두 temperature 규칙을 함께 평가하고 submission_{SEED}_T0.3.csv, submission_{SEED}_T0.5.csv를 생성한다.
5. 단순 평균·가운데 두 값 평균·두 temperature 규칙, 의견 일치 유형별 ACC·Log Loss를 저장한다.
6. 전체 셀 문법·실제 증강 출력·결과 경로·코드 보관·패키지 구성을 검증했다. 학습은 사용자가 루트 노트북에서 실행한다.

T0.3은 일치 0.3·불일치 0.7인 기존 규칙이고, T0.5는 전체 0.5 규칙이다.
앙상블 파라미터는 16,035,316개다.

## 비교

실험 006과 같은 검증 이미지에서 시드별 결과와 두 앙상블 결과를 비교한다.
가림·원근 모델이 strong 기반에서 개선되는지, 기본형을 strong으로 바꿨을 때 오답 겹침과 앙상블 손실이 어떻게 변하는지 확인한다.
Public 점수는 사용자가 각 CSV를 직접 제출해 별도로 기록한다.

### 채택 판단

기본형과 원근형의 strong 강화는 두 분할 모두 개별 손실을 낮췄으므로 후속 실험의 기본 설정으로 채택할 근거가 있다. 가림형은 한 분할에서 크게 개선되고 다른 분할에서 소폭 악화돼 007·008의 현재 설정을 유지하며 추가 확인한다. 전체 strong 기반 구성을 후속 비교의 기준으로 사용한다.

조건부 T0.3 앙상블과 TTA의 우세는 분할·구성별로 달라진다. 기존 005의 Public 0.0045 제출을 최종 후보로 유지한다. 최종 제출 선택에는 같은 규칙의 Public 결과와 CPU 재현을 함께 확인한다.
