# 실험 005 — Log Loss 기준 4모델과 비율 보존 입력

실행 완료. 아래는 당시 분할 seed 42, 모델 seed 42–45 조건이다. 현재 루트 코드는 실험 006·007용이다.

## 모델과 증강

모델은 모두 EfficientNet-B0다. 각 실행은 ImageNet 사전학습 가중치에서 시작한다.
시드와 증강 구성은 다음과 같다.

| 시드 | 구성 | 크롭 면적 | 밝기·대비 | 채도 | 추가 변환 |
|---|---|---|---|---|---|
| 42 | 기본형 | 70–100% | ±30% | ±20% | 없음 |
| 43 | 강규칙형 | 50–100% | ±40% | ±30% | 없음 |
| 44 | 가림 대응형 | 70–100% | ±30% | ±20% | 확률 10%로 면적 2–10% 가림 |
| 45 | 원근 변화형 | 70–100% | ±30% | ±20% | 확률 30%, distortion_scale=0.15 |

모두 좌우 반전 확률 0.5, 크롭 종횡비 범위 0.75–1.3333을 사용한다.
기본형은 과거 medium 설정이다. 추가 증강 수치는 비교 실험의 시작값이다.
가림은 정규화 후 평균값 0으로 적용한다.

## 입력 크기

네 모델 모두 256×256 입력을 사용한다.
학습에서는 원본에서 영역을 자르고, 그 영역의 비율을 유지해 긴 변을 256으로 맞춘 뒤 중앙 패딩한다.
검증·테스트에서는 원본 전체를 같은 비율 보존·패딩 함수로 처리한다.
원본이 192×256 또는 256×192이면 크기 조정으로 픽셀을 바꾸지 않고 부족한 방향 양쪽에 32픽셀씩 여백을 더한다.
패딩 RGB는 기존 정규화 평균에 가까운 (124, 116, 104)다.
이번 구현에서는 4개 모델에 모두 비율 보존 256 입력을 적용했다. 224 입력과의 별도 대조 학습은 포함하지 않았다.

## 학습과 선택

- 데이터 분할은 seed 42, 검증 비율 15%로 고정한다. 네 모델의 학습·검증 인덱스가 같다.
- Adam, batch size 32, workers 0, 최대 50 epoch를 사용한다.
- 학습 손실은 BCEWithLogitsLoss다.
- 전체 최저 검증 Log Loss 가중치를 저장한다. 손실이 같은 경우 ACC가 높은 가중치를 선택한다.
- 학습률은 0.001 → 0.0003 → 0.0001이다.
- 각 학습률에서 최소 5 epoch를 학습하고, 이후부터 단계 내 최저 검증 Log Loss를 연속 5회 갱신하지 못하면 전환한다.
- 단계 전환 시 단계별 최저 손실과 대기 횟수를 초기화한다. 전체 최고 가중치는 이어서 보관한다.
- 마지막 학습률에서도 같은 조건이면 종료한다. 정체가 지속되면 10·20 epoch 종료 후 전환하고 30 epoch에서 종료한다.
- 전체 50 epoch 상한이 우선한다.
- 모든 epoch의 학습률·단계·단계 내 epoch·학습/검증 손실과 ACC를 CSV에 즉시 기록한다.

## 앙상블

각 모델의 IT관 확률을 0.5 기준으로 분류해 의견을 구한다.

| 의견 | 결합 확률 | Temperature |
|---|---|---|
| 전원 일치 | 네 확률의 평균 | 0.3 |
| 불일치 | 정렬한 확률 중 가운데 두 값의 평균 | 0.7 |

결합 확률 p에 sigmoid(logit(p)/T)를 한 번 적용한다.
중앙 두 값의 평균이 0.5이면 최종 확률도 0.5다.
모든 확률이 0 또는 1인 경우도 유효한 확률로 처리한다.
총 파라미터는 16,035,316개다.
노트북·제출 predict.py 모두 model.py의 동일한 전처리와 결합 함수를 사용한다.

## 추가 제출 후보 — 기존 005 가중치의 TTA

학습·제출 시간이 제한된 상황에서, 기존 최고 Public #49의 가중치를 유지한 TTA 후보를 생성했다. 추가 학습은 수행하지 않았다. 구성은 기존 basic42·strong43·basic+가림44·basic+원근45이며, 모델별 원본·좌우 반전 확률 평균 후 기존 조건부 T0.3을 적용한다. 사용자는 2026-11-08 17:52 KST에 #80으로 제출했고 Public은 **0.0044**였다.

- `제출 후보 CSV` (과거 산출물; 현재 파일 없음)
- [가중치·코드 해시와 재현 확인 기록](실험설정.md)

기존 가중치를 GPU에서 원래 계산 조건으로 추론했을 때 저장된 개별 검증 확률과 최대 차이는 0, #49 보관 CSV와의 최대 차이는 약 0.00000049였다. 다만 TTA 추론에서는 cuDNN TF32 사용 GPU와 제출용 CPU 결과의 최대 차이가 약 0.06203으로 발견됐다.

최종 후보 CSV는 루트 predict.py의 CPU 추론으로 생성했다. TF32를 끈 GPU 추론과 비교한 최대 차이는 약 0.00000130이다. 이 정밀도 조건의 검증 손실은 기본 T0.3 0.01165962, TTA 0.01340630이며 오답은 모두 2장이다. 따라서 검증에서는 TTA가 악화됐다. 기존 #49 추론과는 TTA 외에 계산 정밀도도 달라 엄밀한 TTA 단독 비교는 아니다.

테스트 500개 ID와 유효 확률을 확인했고, #49와 분류가 달라진 사진은 1장이다. CSV SHA-256은 `da04afa371731cef0d8e2dd6524bbb8d9f8b0d07ea885e95f1838f7b1accbb4f`다. #80은 기존 #49의 0.0045보다 낮은 Public을 기록했다. Private 성능과 최종 평가 선택 여부는 미확인이다. 기존 #49·#50 CSV와 가중치는 변경하지 않았다.
