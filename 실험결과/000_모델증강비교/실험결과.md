# 실험 000 — 같은 seed의 모델·증강 비교

18회 학습과 분석 완료. 실행 파일은 프로젝트 루트의 `model_transform_test.ipynb`다. 결과는 `split_5/`에 있으며, 노트북 마지막에 기존 가중치로 제출 CSV를 만드는 셀을 추가했다.

## 고정 조건

검증 분할 seed는 5로 고정하고, 학습 seed 5·6·7에서 같은 조건을 반복한다. 모든 실행은 같은 검증 사진을 사용한다. 결과는 `split_5/`에 저장한다.

입력은 원본 비율 보존 256×256 패딩이다. optimizer는 Adam, batch size는 32, workers는 0이다. 학습률 0.001 → 0.0003 → 0.0001, 단계별 최소 5 epoch 이후 연속 5회 미개선 전환, 최대 50 epoch를 사용한다. 전체 최저 검증 BCE 가중치를 선택한다. 최종 확률 분석은 대회와 같은 1e-6 클리핑 Log Loss를 사용한다. 모든 조합의 학습·추론에서 TF32를 끈다.

## 학습 조합

| 모델 | 증강 | 학습 seed |
|---|---|---|
| EfficientNet-B0 | basic | 5·6·7 |
| EfficientNet-B0 | strong | 5·6·7 |
| EfficientNet-B0 | strong+가림 | 5·6·7 |
| EfficientNet-B0 | strong+원근 | 5·6·7 |
| MobileNetV3 Large | strong | 5·6·7 |
| ResNet18 Places365 | strong | 5·6·7 |

B0 strong을 증강 비교와 모델 비교에서 공유하므로 총 18회다. B0와 MobileNet은 ImageNet V1, ResNet은 기존 로컬 Places365 가중치에서 학습한다.

basic은 크롭 면적 70–100%, 밝기·대비 ±30%, 채도 ±20%다. strong은 크롭 면적 50–100%, 밝기·대비 ±40%, 채도 ±30%다. 가림은 strong에 확률 10%·면적 2–10% Random Erasing을 추가한다. 원근은 strong에 확률 30%·distortion_scale 0.15 Random Perspective를 추가한다. 좌우 반전 확률은 모두 0.5다.

## 실행과 재사용

노트북을 저장한 뒤 프로젝트 루트의 별도 커널에서 전체 실행한다. 각 조합은 사전학습 가중치에서 새로 시작한다. epoch CSV는 매 epoch 즉시 기록하며, 조합별 최적 가중치·검증 예측·지표·학습 곡선을 저장한다.

`completed.json`은 조합의 산출물을 모두 저장한 뒤 기록한다. 재실행 시 설정·원본 이미지 내용·학습 코드·라이브러리·완료 산출물 해시가 일치하는 실행을 재사용한다. 완료 표시가 없는 조합은 처음부터 다시 학습한다. 완료된 다른 조합은 재사용할 수 있다. 설정이나 파일이 달라진 완료 실행은 명시적 오류로 알린다.

## 분석 파일

| 파일 | 내용 |
|---|---|

| `all_validation_predictions.csv` | 모든 실행의 이미지별 확률·정답 확률·오답 여부·손실 |
| `group_agreement.csv` | seed별 네 증강 및 세 모델 그룹의 전원 일치 오답·앙상블 지표 |

| `분석결과.md` | 조건별 성능·같은 seed의 쌍별 오답·전원 일치 오답 요약 |

쌍별 비교는 공통 오답·각자만 틀린 사진·분류 불일치·오답 Jaccard를 기록한다. A가 틀린 사진에서 B의 정답 확률이 개선됐는지와 손실 기여가 어떻게 바뀌었는지도 기록한다. 두 모델이 모두 전부 맞힌 경우 Jaccard는 빈칸으로 표시한다.

그룹 분석은 전원 일치 시 평균 확률·T=0.3, 불일치 시 가운데 확률(네 모델이면 가운데 두 값 평균)·T=0.7을 사용한다. 그룹 크기가 다른 두 구성의 성적은 각 구성에 대한 관찰로 해석한다.

같은 검증셋에서의 세 학습 seed 변동은 새 사진에서의 일반화 오차범위를 나타내지 않는다. 오답 개수·겹침과 전체 Log Loss를 함께 검토한다.

## 제출 후보 — strong 5·가림 6·원근 7, 조건부 T0.3 TTA

사용자가 요청한 B0 strong·strong+가림·strong+원근 3개를 사용한다. 서로 다른 학습 seed를 쓰는 방향으로 strong=5·가림=6·원근=7을 순서대로 고정했다. 같은 학습·검증 분할을 사용하므로, 다른 학습 seed가 Private 성능 개선을 보장하지는 않는다.

노트북 마지막의 `SUBMISSION_MEMBERS`에서 구성을 지정한다. 기존 학습 완료 커널에서는 마지막 제출 셀만 실행하면 된다. 각 모델의 원본·좌우 반전 sigmoid 확률을 평균하고, 전원 일치이면 세 확률 평균에 T=0.3, 불일치이면 가운데 확률에 T=0.7을 적용한다.

| 검증 436장 | 오답 | Log Loss |
|---|---:|---:|
| 조건부 T0.3, TTA 미적용 | 1장 | 0.00578917 |
| 조건부 T0.3, TTA 적용 | 1장 | 0.00424705 |

세 체크포인트의 완료 기록과 SHA-256을 확인했고, TTA 미적용 개별 검증 확률은 원래 저장된 확률과 최대 차이 0으로 재현됐다. 총 파라미터는 12,026,487개다. 테스트 500개 ID·중복·확률 범위와 CSV의 소수 여섯 자리 저장값을 확인했다. 기존 학습·분석 CSV와 가중치는 변경하지 않았다.

- `제출 CSV` (과거 산출물; 현재 파일 없음)
- [가중치 출처·검증 지표·CSV 해시](실험설정.md)

이 구성은 중간 검토의 세 모델 모두 seed 5인 구성과 다르다. 최종 ZIP 생성과 Colab CPU 시간 검증은 이번 CSV 생성에 포함하지 않았다.

### Public 결과 — #78, 2026-11-08 17:30 KST

사용자가 위 CSV를 제출했고 Public Log Loss는 **0.0235**였다. 검증 TTA 손실 0.00424705가 Public에서도 유지되지는 않았다. 기존 최고 제출 #49의 0.0045보다 높아 현재 최종 제출 후보를 교체할 근거가 없다.

#49의 현재 보관 CSV와 비교하면 테스트 500장 중 6장의 분류가 달라졌고 확률 차이가 0.1 이상인 사진은 11장이었다. 제출 CSV는 위 출처 JSON의 해시와 일치했다. Public 정답과 포함 이미지가 비공개이므로 어느 사진이 점수 악화를 일으켰는지는 특정할 수 없다.

이 비교에서는 분할·증강·모델 개수·학습 seed·TTA가 함께 달라졌다. 서로 다른 학습 seed나 TTA 중 하나가 원인이라고 단정하지 않는다. 다른 학습 seed를 쓰는 방향은 검증에서의 오답 보완에 근거한 후보 전략이며, 이번 조합의 Public 개선은 확인되지 않았다. 실험 000의 모델·증강 비교 결과와 이 제출 조합의 Public 성능을 구분하고, 현재 최종 후보는 #49로 유지한다.
