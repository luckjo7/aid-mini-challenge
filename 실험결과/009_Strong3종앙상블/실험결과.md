# 실험 009 — Strong 증강의 세 구조 앙상블

분할 seed 42 학습·추론 완료. T0.3 TTA Public은 사용자 확인 기준 #60 0.0366이다.

## 목적과 구성

세 모델의 증강을 strong으로 통일하고 서로 다른 모델 구조의 오답 보완 효과를 확인한다.

| 구조 | 모델 seed | 증강 | 준비 방식 |
|---|---:|---|---|
| MobileNetV3 Large | 42 | strong | 008의 seed 42 재사용 |
| ResNet18 Places365 | 44 | strong | Places365 사전학습 가중치에서 새로 학습 |
| EfficientNet-B0 | 43 | strong | 007의 seed 43 재사용 |

모델 이름과 seed의 조합으로 기록한다. SEED=42에서 모델 구성 순서의 seed는 42·44·43이다. 두 ResNet 사전학습 방식 중 001에서 평균 검증 손실이 낮았던 Places365를 선택했다. 해당 비교는 당시 입력·학습 조건의 결과다.

분할 seed는 42, 검증 비율은 15%다. 입력은 비율 보존 256×256 중앙 패딩이다. strong 증강은 크롭 면적 50–100%, 밝기·대비 ±40%, 채도 ±30%, 좌우 반전 확률 0.5이며 가림·원근 변형은 적용하지 않는다.

ResNet은 기존과 같은 Adam·단계별 학습률·최대 50 epoch·단계별 최소 5 epoch와 미개선 5회 규칙을 사용한다. 전체 최저 검증 Log Loss의 체크포인트를 선택한다. 총 파라미터는 19,389,167개다.

## 실행과 재사용

- 루트 `baseline_test3.ipynb`에서 실행한다. 모델·추론 모듈은 `model_test3.py`, `predict_test3.py`다.
- 실행 전에 노트북을 저장한다. 실행 시점의 학습 코드와 모델 코드를 결과 폴더의 `코드/`에 보관한다.
- 재사용할 모델의 완료 기록·모델 이름·seed·strong 설정·학습 설정·검증 ID와 정답을 검사한다.
- 새 학습은 ResNet 한 개다. 재사용 가중치와 epoch CSV·그래프는 009에 복사하고 `runs.csv`에 출처를 기록한다.
- 결과는 `seed_{SEED}/`에 저장한다. `SEED=1`로 변경하면 모델 seed는 1·3·2가 되며, 해당 분할의 008 MobileNet과 007 EfficientNet 결과가 필요하다.

## 세 모델 결합과 제출

| 의견 | 결합 확률 | Temperature |
|---|---|---:|
| 3:0 전원 일치 | 세 확률의 평균 | 0.3 |
| 2:1 불일치 | 정렬한 가운데 확률 | 0.7 |

TTA는 모델별 원본·좌우 반전 확률을 평균한 뒤 같은 결합 규칙을 적용한다. 최종 제출 CSV는 다음 두 개다.

```text
submission_{SEED}_T0.3.csv
submission_{SEED}_T0.3_TTA.csv
```

검증 CSV는 모델 이름으로 확률 열을 구분한다. 두 방식의 전체 지표와 3:0·2:1별 지표를 저장한다. 추론에서는 008과 같이 cuDNN TF32를 꺼 CPU 재현 차이를 줄인다.

## seed 42 완료 검토 — 2026-11-08

ResNet18 Places365는 모델 seed 44로 45 epoch 학습했고 최적 epoch는 40이었다. 학습 시간은 약 349초다. ensemble.pt와 패키지 model.pt의 모델 seed는 42·44·43이며, ResNet 가중치는 seed44 체크포인트와 일치했다. 이전 seed43 체크포인트가 폴더에 남아 있으나 현재 앙상블은 seed44를 사용한다.

기존 007의 B0 seed44 strong+가림은 오답 0장·손실 0.00646이었다. 증강도 달라 이 비교에서 모델 구조만의 효과를 분리할 수는 없다.

### 공통 오답의 확신

MobileNet과 ResNet의 공통 오답은 86b861d7-0a1a-4cd0-bef7-64adfd948e7f 한 장이다. 정답은 제6공학관이다. 기본 예측에서 IT관 확률은 MobileNet 0.99906·ResNet 0.99643·B0 0.00800이었다. 가운데 확률은 0.99643이며, 불일치 T=0.7 적용 후 0.99968이 됐다. 이 한 장이 기본 앙상블 검증 손실의 약 93%를 차지했다.

T=0.7은 전원 일치 T=0.3보다 확신을 덜 높이지만 T=1보다 확신을 높인다. 따라서 의견 불일치 자체가 약한 최종 확신을 보장하지 않는다. 단순 평균 T=1의 손실 0.01311보다 현재 결합·보정 후 손실 0.01986이 높았다.

TTA에서는 같은 사진의 IT관 확률이 0.99988로 더 높아졌고, f96ae15b-9079-4a03-8533-14f26a46894b에서도 새 오답이 생겼다. 해당 사진은 TTA 후 MobileNet과 ResNet이 함께 틀렸다.

### Public과 판단

동일 분할 seed 42의 TTA Public은 007 #57 0.0109, 008 #58 0.0232, 009 #60 0.0366이었다. 009의 현재 구성·결합 규칙은 검증과 Public 모두 008보다 낮은 성능이었다. 모델 구성과 개수 및 결합 규칙이 함께 바뀌었으므로 모델 다양성 전반의 효과로 일반화할 수 없다. Public의 원인 사진과 Private 성능은 미확인이다.
