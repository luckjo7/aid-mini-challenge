# 실험 004 — 약·중·강 증강 앙상블

실행 완료. 아래는 당시 3모델·ACC 기준 설정이며 현재 루트 코드와 다르다.
사용자 정정에 따라 시드 2·3·4는 사용하지 않는다.

## 학습 설정

EfficientNet-B0 세 개를 시드 42·43·44로 학습한다.
학습·검증 분할은 seed 42, 검증 비율 15%로 고정하고 세 모델에서 같은 검증 이미지를 사용한다.
Adam, batch size 32, workers 0, 입력 224×224를 사용한다.
학습률 0.001 → 0.0003 → 0.0001, 단계별 최소 5 epoch 이후 연속 5회 ACC 미개선 시 전환, 마지막 단계에서 같은 조건이면 종료한다.
전체 최대 50 epoch 상한을 적용한다.
모델마다 전체 최고 검증 ACC 가중치를 저장하고, ACC 동률이면 Log Loss가 낮은 것을 선택한다.

## 증강 설정

| 시드 | 증강 | 크롭 면적 비율 범위 | 밝기 | 대비 | 채도 |
|---|---|---|---|---|---|
| 42 | 약 | 0.9–1.0 | 0.1 | 0.1 | 0.1 |
| 43 | 중 | 0.7–1.0 | 0.3 | 0.3 | 0.2 |
| 44 | 강 | 0.5–1.0 | 0.4 | 0.4 | 0.3 |

밝기·대비·채도 값은 ColorJitter 인수다. 예를 들어 밝기 0.3은 0.7–1.3배 변형을 뜻한다.
좌우 반전 확률은 모두 0.5, 색조 변형은 0, 크롭 종횡비는 Torchvision 기본값 0.75–1.3333이다.
중간 단계는 기존 설정이다. 약·강 수치는 건물 단서가 남는 범위를 고려해 정한 실험 시작값이며, 최적값으로 검증한 수치는 아니다.
검증·추론에는 증강을 적용하지 않고 224×224 크기 변경과 기존 정규화를 사용한다.

수치의 의미는 [RandomResizedCrop](https://docs.pytorch.org/vision/stable/generated/torchvision.transforms.RandomResizedCrop.html)과 [변환 예시](https://docs.pytorch.org/vision/main/auto_examples/transforms/plot_transforms_illustrations.html)를 참고했다.

## 앙상블

각 모델의 sigmoid 확률을 계산한 뒤 세 확률을 동일 가중치로 평균 낸다.
평균 확률 0.5 이상을 IT관으로 판단한다.
총 파라미터는 12,026,487개다.
model.py의 EfficientNetEnsemble을 노트북과 제출 predict.py에서 함께 사용한다.

## 출력 파일

- epochs/에 시드별 모든 epoch의 학습률·단계·학습/검증 지표를 즉시 저장한다.
- runs.csv와 summary.csv에 개별 모델 결과와 평균·표준편차를 기록한다.
- ensemble_metrics.csv에 세 모델 각각과 앙상블의 검증 ACC·Log Loss를 기록한다.
- validation_predictions.csv에 검증 이미지 ID·정답·개별 확률·앙상블 확률을 기록한다.
- submission_seed42.csv, submission_seed43.csv, submission_seed44.csv는 개별 모델 제출용이다.
- submission.csv는 앙상블 제출용이다.
- ensemble.pt에 세 모델의 가중치와 시드·증강 이름을 함께 저장한다.
- submission_package.zip에 model.py, predict.py, baseline.ipynb, 세 모델 가중치를 담은 model.pt를 넣는다.
- 마지막 자가 검증 셀은 CPU 추론 시간 600초 이내와 제출 CSV 재현을 확인한다. 실제 Colab CPU에서도 시간 제한을 확인해야 한다.

제출 CSV와 ZIP은 이 실험 폴더에 생성한다. 사용자가 사이트에 직접 제출한다.
이전 실험 003 코드는 `archive` (과거 산출물; 현재 파일 없음)에 보관했다.
