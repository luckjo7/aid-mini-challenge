# 실험 010 — 동일 시드의 B0 4증강 앙상블

추론·CSV·패키지 생성 완료. 추가 학습 없이 000의 완료된 가중치를 재사용한다. 실행 파일은 프로젝트 루트의 `baseline_test4.ipynb`다.

## 목적과 구성

같은 모델 구조와 같은 학습 seed에서 증강을 달리한 네 모델의 제출 성능을 확인한다. 분할 seed는 5로 고정하고 네 모델의 학습 seed도 모두 5다.

| 모델 | 증강 | 학습 seed | 출처 |
|---|---|---:|---|
| EfficientNet-B0 | basic | 5 | 000 basic seed 5 |
| EfficientNet-B0 | strong | 5 | 000 strong seed 5 |
| EfficientNet-B0 | strong+원근 | 5 | 000 perspective seed 5 |
| EfficientNet-B0 | strong+가림 | 5 | 000 erasing seed 5 |

000의 동일 시드 4증강 구성에서 기본 조건부 T0.3 검증 손실은 seed 5가 0.00342272, seed 6이 0.00832294, seed 7이 0.02224938이었다. 사용자가 가장 결과가 좋았던 seed를 요청해 이 기준으로 5를 선택했다. TTA 결과로 세 seed를 다시 탐색한 것은 아니다.

가림과 원근은 strong 기반이며 basic 기반이었던 005의 가림·원근 모델과 구분한다. 같은 검증셋의 결과를 보고 seed를 선택했으므로 이 점수를 독립적인 일반화 성능으로 해석하지 않는다. #78과 비교하면 모델 수·basic 추가·학습 seed가 함께 바뀌어 시드만의 효과로 분리할 수 없다.

## 결합과 산출물

입력·전처리는 기존과 같은 비율 보존 256×256 중앙 패딩이다. 기존 루트 model.py와 predict.py의 4모델 구조·결합·CPU 추론 코드를 수정 없이 재사용하고 010 패키지에 복사했다. 추론의 TF32는 비활성화한다.

- 전원 일치: 네 확률 평균, T=0.3.
- 불일치: 정렬한 가운데 두 확률 평균, T=0.7.
- TTA: 각 모델의 원본·좌우 반전 sigmoid 확률을 평균한 다음 같은 결합 규칙을 적용한다.
- 전체 T0.5도 함께 생성한다.

| 검증 436장 | 오답 | Log Loss |
|---|---:|---:|
| 조건부 T0.3 | 1장 | 0.00342272 |
| 전체 T0.5 | 1장 | 0.00399656 |
| 조건부 T0.3 TTA | 1장 | 0.00482549 |

검증에서는 TTA 손실이 높았다. TTA Public은 사용자 확인 기준 #82 0.0366이며, 기본 T0.3과 전체 T0.5 Public은 미평가다.

- `T0.3 TTA 제출 CSV` (과거 산출물; 현재 파일 없음)
- `기본 T0.3 제출 CSV` (과거 산출물; 현재 파일 없음)
- `전체 T0.5 제출 CSV` (과거 산출물; 현재 파일 없음)
- [검증 지표](seed_5/ensemble_metrics.csv) · `이미지별 검증 확률` (과거 산출물; 현재 파일 없음)
- [재사용 가중치·설정·출처 기록](실험설정.md)
- `최종 패키지` (과거 산출물; 현재 파일 없음)

## 재현 확인

네 체크포인트와 저장된 검증 확률의 SHA-256, 분할·학습 seed·증강·학습 설정·436개 검증 ID 및 정답을 확인했다. 원래 000의 개별 검증 확률은 최대 차이 0으로 재현됐다. 세 제출 CSV는 각각 테스트 500개 ID와 유효 확률을 포함한다.

파라미터는 16,035,316개다. 패키지의 CPU 추론 코드로 테스트 500장 TTA를 다시 실행했고 약 38.38초, 제출 CSV 최대 차이 약 0.000001이었다. 이 시간은 로컬 CPU 측정이며 실제 Colab CPU 시간은 미확인이다. `CPU 확인 기록` (과거 산출물; 현재 파일 없음)에 별도로 저장했다.

ZIP은 60,323,883바이트이며 내부 파일 무결성 검사를 통과했다. model.pt는 ensemble.pt와 일치한다. 패키지에는 010 노트북·기존 모델/추론 코드·네 가중치·출처 기록과, 실제 학습 코드인 000의 보관 노트북을 source_000/에 포함한다. 010에서 새로 학습한 가중치가 아니다.

TTA CSV 재현 명령은 패키지 폴더에서 다음과 같다.

```text
python predict.py --input <test 폴더> --output pred_tta.csv --tta
```

기본 T0.3은 --tta를 생략하고, 전체 T0.5는 --temperature-rule T0.5를 지정한다. 새 커널에서 baseline_test4.ipynb를 전체 실행하면 가중치 재사용부터 CSV와 패키지 생성까지 수행한다. 기존 CSV와 새 결과가 다르면 오류를 내고 기존 CSV를 보존한다.

## Public 결과 — #82, 2026-11-08 18:02 KST

사용자가 010 T0.3 TTA CSV를 제출했고 Public Log Loss는 **0.0366**이었다. 제출 파일 해시는 source_records.json의 T0.3_TTA 해시 `6d3de087afade37db09255ffd8ad8d8666168c71fcaf9874f81c70b0dfddec52`와 일치했다. 검증 0.00482549의 성적이 Public에서 유지되지 않았으며, 최고 Public #80 0.0044를 대체할 근거가 없다.

Public 250장에서 정답 확률 0.0001을 준 오답 한 장만으로 전체 손실 약 0.03684가 발생한다. 따라서 소수 사진에 대한 과도한 오답 확신은 이번 점수 규모를 설명할 수 있으나, 실제 Public 오답이 한 장이라는 증거는 아니다. Public 정답과 포함 이미지가 비공개이므로 원인 사진과 오답 수는 특정하지 못한다.

별도 검증셋에서는 가장 큰 손실 한 장이 TTA 검증 손실의 약 61.43%를 차지했다. 정답은 label 0인데 IT관 확률 0.72539를 주었고, 개별 손실은 약 1.29241이었다. 이 검증 사진을 Public 점수의 원인 사진으로 해석하지 않는다.

동일 학습 seed로 맞추는 것만으로 Public 성능이 개선되지는 않았다. #78과는 모델 수와 증강 구성도 함께 달라 seed만의 인과 효과로 확정하지 않는다. 예측·가중치·패키지는 변경하지 않았다.
