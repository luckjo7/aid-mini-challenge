# 실험 001 — 사전학습 모델 4종 비교

[실험 목록](../README.md) · [개선방안](../../개선과정.md) · [작업정리](../../README.md)

기록일: 2026-11-08. 상태: **4종 × 3시드, 총 12회 완료**.

이 문서는 확인 시점의 기록이며 실시간으로 갱신되지 않는다. 과거 개선방안 메모의 적용 시도와 별개의 정식 비교 실험이다.

이후 변경으로 EfficientNet-B0를 잠정 채택했다. 현재 루트 코드는 EfficientNet-B0만 실행하며, 4종 비교 코드의 정리 직전 버전은 [archive](../README.md)에 보관했다. 아래 설정은 당시 기록 기준이며 결과는 2026-11-08 원본 CSV로 갱신했다.

## 목적

동일한 학습·검증 분할과 학습 설정에서 네 모델의 검증 Log Loss, seed에 따른 편차, 학습 시간을 비교한다. 모든 모델은 전체 파라미터를 추가 학습한다.

| 비교 대상 | 사전학습 데이터 | 확인하려는 것 |
|---|---|---|
| EfficientNet-B0 | ImageNet | 모델 구조와 사전학습 조합의 성능 |
| ResNet18 Places365 | Places365 | ImageNet ResNet18과 비교해 장소 사전학습의 효과 |
| ResNet18 | ImageNet | Places365 ResNet18의 비교 기준 |
| MobileNetV3 Large | ImageNet | 모델 구조와 사전학습 조합의 성능 |

네 모델을 각각 seed 42·43·44로 실행한다. 총 12회이며, 앙상블 실험은 아니다.

## 설정

아래는 **당시 기록된 코드 기준**이다. 실제 실행 당시 커널 변수와 저장 코드의 완전한 일치는 확인하지 못했다.

| 항목 | 값 |
|---|---|
| 학습·검증 데이터 | 제공된 학습 이미지에서 분할. 테스트 이미지 사용 안 함 |
| 검증 비율 | 15%, 클래스 비율 유지 |
| 분할 seed | 42로 고정 |
| 실행 seed | 42, 43, 44 |
| 입력 크기 | 224×224 |
| 학습 증강 | RandomResizedCrop, 좌우 반전, ColorJitter |
| 검증 전처리 | 224×224 크기 변경, 텐서 변환, 정규화 |
| 정규화 평균 / 표준편차 | (0.485, 0.456, 0.406) / (0.229, 0.224, 0.225) |
| epoch / batch size | 12 / 32 |
| optimizer / 학습률 | Adam / 0.001 |
| 손실함수 | BCEWithLogitsLoss |
| DataLoader workers | 0 |
| 반복 시 초기화 | 모델, 사전학습 가중치, optimizer, DataLoader를 새로 준비 |

모든 실행은 같은 증강 정책과 seed 구성을 사용한다. 모델 구조가 다르므로 각 이미지에 실제로 적용된 난수 변형까지 완전히 동일하다고 확인한 것은 아니다.

## 확인된 실행 결과

출처: [원본 runs.csv](model_comparison/runs.csv)의 완료 행 12개. 각 실행에서 최저 검증 Log Loss로 선택한 체크포인트를 비교한다.

| 모델 | 완료 횟수 | 최저 검증 Log Loss 평균 | 표본 표준편차 |
|---|---:|---:|---:|
| efficientnet_b0 | 3 | 0.04338470 | 0.01558709 |
| mobilenet_v3_large | 3 | 0.07306777 | 0.01453594 |
| resnet18_places365 | 3 | 0.10538054 | 0.02883717 |
| resnet18 | 3 | 0.12145243 | 0.01919533 |

EfficientNet-B0의 평균 손실이 가장 낮아 사용자 요청으로 잠정 채택했다. 모델당 파라미터는 4,008,829개다. 학습 시간은 대회에서 요구하는 CPU 테스트 추론 시간과 다르다.
