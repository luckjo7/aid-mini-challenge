# 실험 002 — EfficientNet-B0 단계별 학습률

실행 완료. 세 시드 모두 25 epoch에서 종료했다. 아래 설정은 당시 조건이다.

## 목적과 조건

실험 001의 EfficientNet-B0와 같은 시드 42·43·44를 사용해 단계별 학습률과 학습 기간 연장의 효과를 비교한다.
학습·검증 분할 seed 42, 검증 비율 15%, 입력 224×224, 증강, Adam, batch size 32, workers 0을 사용한다.
각 실행은 ImageNet 사전학습 가중치에서 새로 시작한다.

| 항목 | 기존 조건 | 새 조건 |
|---|---|---|
| 시드 | 42, 43, 44 | 42, 43, 44 |
| 최대 epoch | 12 | 50 |
| 1–10 epoch 학습률 | 0.001 | 0.001 |
| 11–20 epoch 학습률 | 0.001, 기존 실행은 12에서 종료 | 0.0003 |
| 21 epoch 이후 학습률 | 해당 없음 | 0.0001 |
| 조기 종료 | 없음 | 20 epoch 종료 후부터 최저 검증 Log Loss 미갱신을 세어 연속 5회면 종료. 가장 이른 종료 25 |

## 비교 기준

출처는 [기존 runs.csv](../001_사전학습모델비교/model_comparison/runs.csv)의 EfficientNet-B0 행이다.

| 시드 | 기존 최적 epoch | 기존 검증 Log Loss |
|---|---:|---:|
| 42 | 5 | 0.0495298110 |
| 43 | 12 | 0.0549625987 |
| 44 | 12 | 0.0256616984 |

기존 평균 검증 Log Loss는 0.0433847027이다.
실행 후 노트북의 전체 통계 셀에서 `comparison.csv`를 생성한다.
동일 시드의 기존 최저 손실, 새 방식의 첫 12 epoch 최저 손실, 새 방식의 전체 최저 손실과 차이를 기록한다.
차이는 새 값에서 기존 값을 뺀 것으로 음수이면 개선이다.

전체 최저 손실 비교에는 학습률 변경과 학습 기간 연장이 함께 반영된다.
첫 12 epoch끼리 비교하면 학습 기간을 맞춰 11 epoch부터 적용한 학습률 변경의 효과를 살펴볼 수 있다.
과거 실행과 현재 실행의 라이브러리·하드웨어 환경이 완전히 같다는 확인은 아직 하지 않았다.
